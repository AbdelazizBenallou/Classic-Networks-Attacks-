In this lesson, we will learn how to configure, secure, and attack the OpenSSH service, which uses the SSH protocol and relies on both symmetric and asymmetric encryption.

### 1. Introduction to SSH Usage

SSH is widely used to remotely access and manage different types of devices, such as:

* Servers
* Routers
* Switches
* Other network devices

These devices can be configured and controlled securely over a network using SSH.

### 2. Securing SSH Access

To improve security, we apply several best practices:

* Disable password-based authentication
* Use asymmetric encryption (SSH key pairs) for secure login
* Change the default SSH port (optional, to reduce automated attacks)
* Enable logging and monitoring of all connection attempts
* Use tools like Fail2Ban to block repeated failed login attempts

### 3. Lab Environment Setup

To simulate a real enterprise LAN environment, we will use:

* GNS3 for network simulation
* Docker for virtualization
* Kali Linux tools to simulate common SSH attacks

### 4. Practical Lab Scenario

First, we create a simple LAN topology that represents an enterprise network.
Then, we configure external access to internal devices via SSH, simulating real-world remote administration.

### 5. Monitoring and Management

Next, we focus on managing and monitoring SSH access:

* Identify and track IP addresses connecting to devices
* Apply access control and limit unauthorized attempts
* Manage VTY sessions and SSH configurations
* Handle SSH keys and user permissions properly

This ensures secure and efficient remote administration of network devices.
